# TEAM ROMERO BROTHERS

_Este proyecto trata sobre un gimnasio ubicado en Tamaraceite de artes marciales mixtas, _

## INSTRUCCIONES 🚀

_Para utilizar este proyecto tendrás que utilizar una interfaz gráfica. El trabajo contiene Html y Css únicamente_

Para abrirlo debes apretar en el repositorio <code> y tienes muchas opciones para abrirlo.


### SECCIONES 📋

_El header es el encabezado de la página web, mi header contiene el logo del gimnasio pegado a la izquierda, mientras que en la derecha hay tres botones, cada uno indica una función diferente_

_Luego tenemos la primera sección, en la que hacemos uso sobre todo del flexbox. En esta sección llamada "one" encontramos una imagen y un título, luego debajo del título un texto pequeño que explica sobre el tema._

_La tercera sección nos muestra datos introducidos básicos con una imagen debajo y tres cajas con datos y preguntas frecuentes, todo con un hover introducido.

_La cuarta sección es la galería, que se divide en dos partes: la parte de las instalaciones y la parte de los luchadores_

_Por último, tenemos un footer el cual se encuentran dos patrocinadores canarios y un botón de contacto , todo con un backround color verde como en el header_
